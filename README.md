# Щоденний прогноз BTC/ETH

Автоматична система: щоранку хмарний агент Claude готує конкретний прогноз по BTC та ETH,
веде журнал прогнозів із підрахунком точності (Брайер-скор), комітить усе в цей репозиторій
і надсилає повний звіт у телефонний застосунок Claude (а після підключення Gmail — ще й на
пошту).

## Що всередині

| Файл | Призначення |
|---|---|
| `PROMPT.md` | Методичка аналітика (кроки 0–3). Джерело правди для логіки прогнозу. |
| `ROUTINE_PROMPT.md` | Промт, який щодня виконує хмарний агент (обгортка над методичкою). |
| `journal.md` | Журнал прогнозів: відкриті, закриті, уроки, зведений Брайер-скор. |
| `scripts/options.py` | Рахує max pain, put/call, топ-страйки по опціонах Deribit. |
| `reports/YYYY-MM-DD.md` | Архів щоденних звітів. |

## Розклад

- Запуск: **щодня о 4:00 за America/Vancouver**.
- Технічно cron хмарного планувальника працює в UTC і **не стежить за переходом на літній/зимовий час**:
  - встановлено `0 12 * * *` (12:00 UTC) = **4:00 за зимовим часом (PST, з 2 листопада по ~8 березня)**;
  - у літній час (PDT) це буде 5:00 — тоді попроси мене змінити на `0 11 * * *`.

## Доставка

1. **Телефонний застосунок Claude** — працює одразу: агент завершує прогін повним текстом
   звіту, і на телефон приходить сповіщення.
2. **Email** — вмикається після підключення конектора Gmail на claude.ai
   (`claude.ai/customize/connectors`). Промт уже містить крок відправки на
   `polkadot88888888@gmail.com`; щойно конектор підключено — лист почне приходити сам.

## ⚠️ Відомий блокер: доступ до API з хмари (треба раз налаштувати)

Тестові прогони показали: хмарне середовище рутини має **жорсткий проксі вихідної
мережі** й блокує прямі запити до крипто-API (`api.bybit.com`, `www.deribit.com`,
`gamma-api.polymarket.com`, `www.tftc.io` — 403 / DNS not found). Працює лише
`WebSearch`. Без доступу до API звіт виходить порожній («данных нет») — агент чесно
це пише й нічого не вигадує.

Два способи це полагодити:

- **A. Дозволити домени в налаштуваннях мережі середовища** (на `claude.ai/code` →
  Environments → середовище цієї рутини → allowed domains / network). Додати:
  `api.bybit.com`, `www.deribit.com`, `gamma-api.polymarket.com`, `www.tftc.io`
  (опц. `api.coingecko.com`, `api.binance.com`). Найпростіше, якщо план дозволяє
  редагувати це.
- **B. GitHub Actions-конвеєр даних**: окремий workflow у цьому репо (рядок cron
  ~03:55 Vancouver) тягне дані з API (у Actions відкритий інтернет), рахує max pain і
  кладе `data/snapshot.json` у репо. Рутина о 4:08 читає готовий знімок із
  склонованого репо — жодної залежності від проксі. Надійніше, але більше збірки.

## Чесно про межі

Це **експеримент із калібрування прогнозів**, а не торговий сигнал. Щоденний прогноз НЕ
робить торгівлю «впевненою»: крипторинок значною мірою непередбачуваний, і сенс журналу —
саме чесно виміряти, наскільки точні прогнози (Брайер-скор), а не створити ілюзію впевненості.
Рішення про угоди — лише твої. Остання стрічка кожного звіту це прямо фіксує.

## Ручний запуск / зміни

- Подивитися/змінити рутину: https://claude.ai/code/routines
- Запустити прогноз зараз: кнопка «Run now» у рутині.
- Змінити годину, мову звіту (рос./укр.), біржу, додати активи — напиши Claude, що саме.
